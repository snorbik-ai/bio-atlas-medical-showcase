Bio-Atlas V2 : De l'Anomalie Filtrée au Compte-Rendu Structuré

Bio-Atlas ne réinvente pas MobiDetails : il se branche dessus pour automatiser les 2 tâches les plus chronophages du médecin : le filtrage du dossier complet et la rédaction structurée du compte-rendu diagnostique.

✓ Complémentaire à MobiDetails ✓ Sortie IA en JSON Structuré Strict ✓ Zéro Fuite RGPD (SHA-256 RAM)

1. Pourquoi Bio-Atlas ? (Complémentaire à MobiDetails)

Ce que MobiDetails (CHU Montpellier) fait en 5 secondes :
  • • Annoter 1 variant ciblé déjà identifié par le médecin.
  • • Afficher les scores in silico (MPA, CADD, SpliceAI, gnomAD, ClinVar).
  • • Limite : Ne filtre pas un dossier patient complet et ne rédige pas le compte-rendu adapté au patient.
La Vraie Valeur Ajoutée de Bio-Atlas V2 :
  • • 1. Filtrage Dossier : Extrait automatiquement les anomalies actionnables d'un VCF de 50 000 lignes + PDF clinique (Docling).
  • • 2. Enrichissement Automatique : Interroge MobiDetails + CIViC v2 + PDB 3D sans copier-coller manuel.
  • • 3. Rédaction Compte-Rendu Structuré (JSON) : Remplit le modèle type du médecin selon les anomalies et le patient, affiché prêt à valider dans l'interface graphique.

2. Qui Fait Quoi ? (Moteur MCP vs IA JSON Structuré)

1. PARE-FEU & FILTRAGE

Dossier & Anomalies

Destruction du nom en RAM (SHA-256). Extraction PDF (Docling) + filtrage déterministe des variants (VAF, DP, gnomAD, panel gènes).

2. MOTEUR MCP

Enrichissement Certifié

Interroge MobiDetails (MPA/CADD), ClinVar, CIViC v2 (thérapies) et calcule les coordonnées 3D sur RCSB PDB.

3. IA STRUCTURÉE (JSON)

Modèle Compte-Rendu

Reçoit les anomalies + preuves + modèle CR du médecin. Produit un JSON strict (Pydantic) sans hallucination.

4. INTERFACE & EXPORT

Affichage Structuré UI

L'UI affiche chaque section du CR (Indication, Anomalies, Conclusion RCP) + la 3D WebGL. Le médecin valide en 1 clic (PDF/DMP).

3. Diagramme de Séquence : De l'Anomalie au Compte-Rendu Validé

Flux complet montrant comment l'IA reçoit les anomalies filtrées et produit un JSON structuré affichable directement dans la console du médecin.

ÉTAPE 1
Dossier Patient ➔ Pare-Feu RGPD
Réception du VCF complet + PDF clinique (Docling). Le nom est haché en RAM (MED-ANON-XXXX) et détruit.
ÉTAPE 2
Moteur MCP (Filtrage Molécules)
Filtrage déterministe des milliers de lignes VCF (VAF, qualité, rareté, panel oncologique) ➔ isole les anomalies prioritaires.
ÉTAPE 3
MCP ➔ MobiDetails / CIViC / PDB
Appels API automatiques vers MobiDetails (scores MPA/CADD), CIViC v2 (thérapies ciblées) et RCSB PDB (coordonnées 3D).
ÉTAPE 4
IA (Structured Output JSON)
L'IA reçoit : Anomalies filtrées + Preuves MobiDetails/CIViC + Modèle type de Compte-Rendu. Elle retourne un JSON strict validé par Pydantic (zéro texte libre).
ÉTAPE 5
UI Structurée + 3D ➔ Médecin
L'interface (localhost:8529) affiche le Compte-Rendu pré-rempli section par section + le modèle 3D WebGL. Le médecin ajuste si besoin et valide/exporte en PDF DMP.
